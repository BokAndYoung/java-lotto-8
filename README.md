######################## # 로또 (Lotto) - Java Precourse

## 📌 기능 요구 사항 정리

### 1️⃣ 입력 기능

- [ ]  구입 금액을 입력받는다.
  - [ ]  1,000원 단위인지 검증한다. 아닐 경우 예외 처리 (`IllegalArgumentException`)
- [ ]  당첨 번호를 입력받는다.
  - [ ]  번호는 6개, 쉼표로 구분
  - [ ]  1~45 범위인지, 중복 없는지 검증
- [ ]  보너스 번호를 입력받는다.
  - [ ]  1~45 범위인지, 중복인지 검증

---

### 2️⃣ 로또 발행 기능

- [ ]  구입 금액 / 1000 만큼 로또를 생성한다.
- [ ]  각 로또는 **중복 없는 숫자 6개**를 가진다.
- [ ]  생성된 번호는 오름차순으로 정렬한다.
- [ ]  생성된 모든 로또 번호를 출력한다.

---

### 3️⃣ 당첨 결과 계산 기능

- [ ]  당첨 번호와 비교하여 일치 갯수를 판단
- [ ]  보너스 번호 일치 여부 판단
- [ ]  아래 기준에 따라 등수 판정 및 당첨 개수 계산


| 등수 | 조건                   | 상금            |
| ---- | ---------------------- | --------------- |
| 1등  | 6개 번호 일치          | 2,000,000,000원 |
| 2등  | 5개 + 보너스 번호 일치 | 30,000,000원    |
| 3등  | 5개 번호 일치          | 1,500,000원     |
| 4등  | 4개 번호 일치          | 50,000원        |
| 5등  | 3개 번호 일치          | 5,000원         |

---

### 4️⃣ 수익률 계산 및 출력 기능

- [ ]  총 당첨 금액 계산
- [ ]  수익률 = (총 당첨 금액 / 구입 금액) * 100
- [ ]  소수점 둘째 자리에서 반올림하여 출력

---

### 5️⃣ 에러 처리 공통 사항

- [ ]  입력이 잘못되면 `IllegalArgumentException` 발생
- [ ]  `[ERROR]`로 시작하는 메시지를 출력하고 **해당 입력부터 다시 진행**
- [ ]  `System.exit()` 사용 금지

---

## ✅ 프로그래밍 요구 사항

- JDK 21
- `Application`의 `main()`에서 프로그램 시작
- 클래스, 패키지 변경 금지 (명시된 범위 내 제외)
- 메서드 길이 15라인 이내, 들여쓰기 2 depth 이하
- `else`, `switch/case`, 3항 연산자 금지
- **Enum 적용**
- 테스트 코드 작성 (UI 로직 제외)
- `Randoms.pickUniqueNumbersInRange` 사용
- `Console.readLine` 사용
